# 01 - Game Design Core

## Run Structure

Run = 8 Antes
Each Ante:
1. Small Blind (optional skip for tag reward)
2. Big Blind (rule modifier)
3. Boss Blind (review pressure)

## Hand Rules

- Plays per blind: 4
- Discards per blind: 3
- Hand size: 8
- Max cards played per hand: 5

## Scoring Formula

Score = (Base chips + card chips) x (Base mult + additive mult) x (multiplicative chain)

## Card Axes

- Elements (5): Life, Force, Mind, Matter, Abstract
- Part of speech (4): Noun, Verb, Adjective, Adverb

## Learning Levels

- Lv0 Unknown
- Lv1 Recognition
- Lv2 Listening
- Lv3 Spelling
- Lv4 Mastered

## Answer Handling

- Correct: full value
- Wrong: reduced value, but still counts toward hand type

This keeps strategic flow intact.
