# 02 - Meta Progression

## Model

Hybrid model:
- Primary: Academy progression
- Secondary: Contract acceleration

## Currencies

- XP: account progression
- LP: unlock economy

## Persistence Policy

- Soft reset run state each run
- Persist learning and meta progression

## Curriculum Tree

- 4 branches x 12 layers
- ~30% mutual exclusion
- Branches:
  - Fluency
  - Lexicon
  - Build Literacy
  - Mastery

## Contracts

At run start:
- choose 1 of 3
- or refresh once
- or skip

Constraints:
- no fail penalty
- bonus LP cap: <=45% of run total LP

## Lexicon Unlock

Tier unlock requires:
1. prior-tier coverage
2. run-count threshold
3. LP cost
