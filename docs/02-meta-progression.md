# 02 - 局外 Meta 規格

## 1. 模型

Hybrid：
- 主系統：學院進程（穩定成長）
- 輔系統：契約加速（短期目標）

## 2. 貨幣

- XP：帳號等級進程
- LP：解鎖經濟（課程樹/詞庫層級）

限制：
- 局內金幣不可兌換 LP
- 契約失敗無倒扣

## 3. 軟重置策略

每局重置：
- 手牌、暫時 Build、局內詞條狀態

跨局保留：
- 單字學習等級
- XP/LP
- 課程樹節點
- 詞庫層級解鎖
- 成就
- 牌組模板

## 4. 課程樹（4 分支 x 12 層）

- Fluency（答題穩定）

- Build Literacy（商店與養牌效率）
- Mastery（精通長線收益）

## 5. 契約池規格

### 5.1 生成流程

- Run 開始顯示 3 張契約
- 可免費刷新 1 次
- 可選擇跳過

### 5.2 類型權重

- 自然契約：40%
- 學習契約：40%
- 風格契約：20%

### 5.3 難度分層

- Tier 1：低門檻，獎勵 4-6 LP
- Tier 2：中門檻，獎勵 7-10 LP
- Tier 3：高門檻，獎勵 11-15 LP

### 5.4 獎勵邊界

- 契約額外 LP 必須 <= 當局總 LP 的 45%
- 契約失敗僅失去加成，不倒扣

## 8. 詞庫演進演算法（完整）

### 8.1 五池模型

- `Locked`：未解鎖池（不可抽）
- `Discoverable`：已解鎖待發現池
- `Learning`：Lv.0-3 學習中池
- `Mastered`：Lv.4 精通池
- `Decayed`：退化池

### 8.2 每局抽樣比例（52 張）

| 池 | 目標張數 | 優先權 | 設計意圖 |
|---|---:|---|---|
| Decayed | 8-12 | 最高 | 強制回補快忘詞 |
| Learning | 20-25 | 高 | 形成主學習密度 |
| Discoverable | 8-12 | 中 | 持續引入新詞 |
| Mastered | 5-8 | 低 | 提供穩定器與節奏加速 |
| Locked | 0 | 無 | 未解鎖不進池 |

備註：
- 若某池不足，按 `Learning -> Discoverable -> Mastered` 順序補位。

### 8.3 反重複與多樣性規則

1. 冷卻權重  
- 上一局出現過的詞，本局權重 x0.5。

2. 長期未出現補償  
- 連續 3 局未出現的 Learning 詞，權重 x2。

3. 同局不重複  
- 同一局內不重複抽取同 wordId。

4. 平衡補齊  
- 抽樣中若元素或詞性偏斜，系統提高缺口類別權重。

### 8.4 滴入式擴展規則

解鎖新層條件：
1. 前層 Lv.2+ 覆蓋率達標
2. 累積局數達標
3. 支付 LP

滴入速度（新層詞進入 Discoverable）：

| 當前精通率 | 每局新增詞數 |
|---:|---:|
| 60% | 1-2 |
| 70% | 3-4 |
| 80% | 5-6 |
| 90%+ | 新層成為主力來源 |

### 8.5 成就加速器（詞庫向）

| 成就 | 觸發 | 加速效果 |
|---|---|---|
| 同族大師 | 同族花通關 5 次 | 該元素進階詞權重提升 |
| 語法達人 | 語序鏈通關 10 次 | 動詞/副詞新詞權重提升 |
| 完美學者 | 單局全對 10 次 | 滴入速度 x1.5（上限控管） |
| 賭神 | 賭一把成功 20 次 | 稀有長詞池權重提升 |
| 收藏家 | 精通 100 個不同詞 | 下一層額外 +50 詞預注入 |

### 8.6 演算法護欄

1. 單局新詞上限  
- 新詞（Discoverable 首次出現）不超過 12 張，避免學習負擔爆量。

2. 契約與詞庫交互上限  
- 契約不得把同一池權重推到超過基準的 2.5 倍。

3. 保底可玩性  
- 每局至少 3 張 Lv.1+ 可穩定出牌詞（避免前期極端卡手）。
