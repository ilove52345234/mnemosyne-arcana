## 4. 關鍵發現

1. 在現實記憶基線（0.85/0.8）下，M1（2000）仍會退回到 M0 卡點。
2. M9（10000）在未提升 retention/retrieval 前，只能落在 M5 範圍（卡在 Ante 6）。
3. 若要達成「10000 詞可通關 Final」，必須提升：
- retention/retrieval（學習品質）
- 或調整 gate 門檻映射（平衡策略）

## 5. 下一步建議

1. 先維持模型不動，針對 retention/retrieval 做可觀測成長機制（回補關與主動回憶題比例）。
2. 用同一份 sweep 每次回歸，避免調參漂移。
3. 等你確認目標體感後，再決定是否調整模型門檻或只調學習機制增益。
