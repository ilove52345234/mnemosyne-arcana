# S10 Formal UI Replan (Round-3)

## 目標
把現有 Prototype UI 調整為玩家可玩的正式版骨架，移除開發調參導向操作。

## 範圍
- 保留：核心遊玩流程（手牌、答題、盲注、商店）。
- 移除/隱藏：調參與開發驗證按鈕區。
- 不做：美術定稿、動畫精修、完整 UI skin。

## 實作步驟
1. 在 `PrototypeCardGameUiController` 新增 `PlayerMode`（預設 true）。
2. `PlayerMode=true` 時隱藏：
   - 調參按鈕列（難度切換、籌碼加減、模型切換）
   - 開發流程按鈕（一鍵通關、連跑3局、全流程驗收、10模型驗證）
3. 重新排列左欄結構：
   - HUD -> 手牌列 -> 上桌列 -> 答題區 -> 行動列 -> 商店列
4. 保留必要操作按鈕：
   - `抽新手牌`
   - `開始答題並出牌`
   - `結算盲注`
   - `前往下一關`
   - `生成商店商品`
   - `購買第一項`
5. 更新 `S10UiLocalizationTests`：
   - 新增「玩家模式不顯示調參按鈕」測試
   - 保留既有 `M1~M5`

## 驗測
- 目標測項：`S10UiLocalizationTests` 全綠（含新 M6）。
- 證據：Unity MCP EditMode job id。

## Done 判定（本輪）
1. 玩家畫面不含調參區與開發按鈕。
2. 牌列操作、答題出牌、商店購買可完整走通。
3. 測試全綠且文件回填完成。
