# S10 - UI/UX（正式可玩版重規劃）

## 1. 設計規劃
- 目標：把現有 Prototype UI 從「開發調參工具」升級為「玩家可玩的正式介面骨架」。
- 方向：參考小丑牌（Balatro）資訊密度與操作節奏，但保留本專案學習答題流程。
- 必要原則：
1. 不顯示開發者調參按鈕給玩家。
2. 核心流程一屏可完成：抽牌 -> 選牌/上桌 -> 答題 -> 出牌 -> 結算盲注 -> 商店。
3. 除學習內容外，介面文案維持繁體中文。

## 2. 規格文件
- P0 優先規格：
1. `docs/systems/S10-ui-ux/PRIORITY_P0_CARD_QUIZ_CAST_FLOW.md`
- UI 區塊（正式版 v1）
1. `Top HUD`：關卡、目標分、目前分、剩餘出牌、金錢。
2. `Hand Row`：5 張手牌，可點擊/拖曳上桌，顯示選取狀態。
3. `Play Row`：已上桌牌列，可撤回、可重排（至少保留撤回）。
4. `Action Row`：`開始答題並出牌`、`結算盲注`、`前往下一關`。
5. `Shop Row`：商品卡清單與購買操作。
- 禁止區塊（正式版）
1. 調參面板（難度切換、籌碼加減、模型切換、自動驗證按鈕）。
2. 開發演示按鈕（連跑3局、一鍵跑到通關、失敗後重開演示）。
- 驗收門檻（round-3）
1. 玩家介面中無調參/開發按鈕。
2. 三個核心操作可用：上桌、答題出牌、商店購買。
3. `S10` 專屬測試全綠，且有 MCP job 證據。
