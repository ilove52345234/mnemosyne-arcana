# P02 Run Table - SYSTEM

## 1. 頁面目標
- 完成核心回合操作：選牌、理牌、出牌、棄牌。

## 2. 版面規範
- 上半部：已選牌/打出牌展示區。
- 下半部：手牌扇形陳列 + 操作列。
- CTA 優先順序：`出牌` > `理牌` > `棄牌`。

## 3. 互動
- 點牌可選取/取消選取。
- 支援拖曳到目標區（若有）。
- `理牌`可切換排序（如點數/花色）。

## 3.1 P0 優先流程（選牌答題後出卡）
- 玩家先選牌，按 `出牌` 後進入「逐張答題」。
- 每張卡在中央放大，題型可為：
  - 中文選項
  - 拼字
  - 發音按鈕（可先佔位）
- 全部答題完成後，才執行依序出卡動畫。
- 出卡後翻轉卡面，揭露答案與美術佔位。
- 詳細規格：`docs/systems/S10-ui-ux/PRIORITY_P0_CARD_QUIZ_CAST_FLOW.md`

## 4. 驗收
- 8 張手牌在橫向手機可讀，不重疊不可點。
- 出牌前後分數區更新延遲 < 300ms（視覺感受）。
- P0 流程中，答題未完成前不得進入實際出卡與結算。
