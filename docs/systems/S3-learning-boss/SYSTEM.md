# S3 - Learning（答題、三選一、Boss）

## 1. 設計規劃
- 目標：學習嵌在玩法內，不做跳窗式中斷。
- 核心原則：答錯降收益，不破壞組牌成立。

## 2. 規格文件
- 等級行為：Lv0(4選1) -> Lv1(2選1) -> Lv2(2選1聽力) -> Lv3(拼字) -> Lv4(免答)。
- 答錯後三選一：
- AcceptLoss：免費接受降益
- RetryWithCost：花費重答（單題一次）
- Gamble：50% 回復 / 50% 歸零
- 保底：連錯 3 題降難，連錯 5 題該關剩餘題型進一步降難。
- Boss 規則：
- 題型整體 +1 階
- Lv4 在 Boss 以 Lv3 行為處理
- 每連對 3 題下一張卡 x2
- Boss 全對後，當 Ante 打出卡可 +1 等級（有上限）
