# S5 - Shop/Economy

## 1. 設計規劃
- 目標：低資金仍有選擇，高資金仍需取捨。
- 核心原則：經濟服務 build 決策，不直接保證勝利。

## 2. 規格文件
- 收入：通關獎勵、剩餘出牌/棄牌轉金、利息、特定表現獎勵。
- 支出：訓練、重答、語感/教材/詞綴/課程、重擲。
- 商店結構：商品區 + 養牌區 + 卡包區，Boss 後課程二選一。
- 價格帶固定，重擲為遞增成本。
- Ante 分段權重：前期偏養成，中期偏 build，後期完整池。
